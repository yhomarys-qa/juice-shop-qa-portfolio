# 🧪 OWASP Juice Shop – End-to-End QA & Software Testing Portfolio

## 📌 Project Overview
This repository showcases a comprehensive, professional-grade quality assurance and test engineering lifecycle applied to the **OWASP Juice Shop** application. 

The goal of this project is to demonstrate practical expertise in structured test documentation, functional execution tracking, and defect management. Every artifact follows industry-standard QA methodologies used by high-performing software development teams.

---

## 📂 Repository Architecture & Artifacts

This portfolio is structured to showcase the core testing artifacts developed for the OWASP Juice Shop project. Each directory contains the technical documentation for specific phases of the QA lifecycle:

* **01-Requisitos-BDD**: User stories, behavior-driven development scenarios, and acceptance criteria.
* **02-Plano de Teste**: Testing scope, objectives, environment strategy, and resource planning.
* **03-Suíte de Teste de Fumaça**: High-priority test cases to ensure core stability after build deployments.
* **04-Conjunto de Testes de Regressão**: Comprehensive test suite covering critical pathways and boundary conditions.
* **05-Relatórios de Execução de Testes**: Execution metrics, bug reports, and final quality assessment results.

---

## 📈 High-Level Execution Metrics & Results

A full functional and regression test suite was executed against the target environment. The delivery assessment yielded the following data points:

* **Total Test Cases Executed:** 400
* **Overall Pass Rate:** **88%**
* **Total Unique Logged Bugs:** 16
* **Final Release Recommendation:** **REJECTED** (Due to critical blockers in the donation payment engine and high-severity security vulnerabilities).

---

## 🔍 Core Methodologies Applied

* **Black-Box Testing Techniques:** Boundary Value Analysis (BVA) and Equivalence Partitioning (EP) were utilized to validate critical input fields.
* **Risk-Based Testing:** Prioritization of execution focused on core revenue-generating and security-sensitive pathways.
* **Defect Lifecycle Management:** Formal reporting focusing on clear steps to reproduce, accurate environment logs, and strict severity/priority classification.
