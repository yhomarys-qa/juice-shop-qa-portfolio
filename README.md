## 📈 High-Level Execution Metrics & Results

A full functional and regression test suite was executed against the target environment. The delivery assessment yielded the following data points:

* **Total Test Cases Designed & Executed:** 400
* **Passed Scenarios:** 352
* **Failed Scenarios (Defects):** 48
* **Overall Pass Rate:** **88%**
* **Total Unique Logged Bugs:** 16
* **Final Release Recommendation:** **REJECTED** (Due to critical blockers in the donation payment engine and high-severity password validation bypasses).

---

## 🔍 Core Methodologies Applied

* **Black-Box Testing Techniques:** Bounday Value Analysis (BVA) and Equivalence Partitioning (EP) were utilized to validate fields like user registration inputs, checkout text spaces, and payment data.
* **Risk-Based Testing:** Prioritization of execution blocks centered on the absolute core revenue-generating pathways (Checkout, Address Validation, and Donation Gateways).
* **Defect Lifecycle Management:** Formal reporting focusing on clear steps to reproduce, accurate environment logs, and strict severity/priority sorting to streamline developer triages.
